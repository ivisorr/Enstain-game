# Обучение

## Цели

1. Программирование на реальном веб-проекте.
2. Работа с AI: постановка задач, совместная разработка и проверка результата.
3. Работа с двух компьютеров через GitHub.
4. CI/CD, начиная с автоматических проверок.

Цели могут дополняться. Понимание важнее скорости.

## Исходный опыт на 2026-11-09

| Область | Самооценка пользователя |
|---|---|
| HTML/CSS | Достаточно уверенно |
| JavaScript | Понимает код AI; методы и API пока знает недостаточно |
| Git/GitHub | Синхронизирует работу дома и на работе; использует main |
| Терминал | Небольшой опыт |
| Ветки и тесты | Практического опыта нет |
| CI/CD | Учебная цель; исходный опыт не уточнён |

## Формат обучения

Обсудить задачу → AI кратко объясняет небольшой шаг → пользователь пробует → вместе проверить и разобрать.

- Готовый код и изменения кода — только по запросу пользователя.
- Объяснения краткие; непонятное пользователь спрашивает сам.
- AI помогает выбирать инструменты, проверяет код и учит понятному, поддерживаемому коду.
- Тесты и CI/CD вводятся с объяснением назначения на практических задачах.
- AI предлагает сохранять памятки важных операций, включая работу с инструментами.
- Опыт обновляется по фактически выполненным и понятным действиям. Объяснение темы само по себе не означает её освоение.

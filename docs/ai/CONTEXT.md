## Реализовано
- src/js/engine.js: каталог ID 3 × 3, elementPositionById, случайная матрица answer, answerPositionById, visibleElements.
- Публичные методы: startGame(), endGame(), getElements(), getVisibleElements(). Геттеры копируют массив и строки. После старта visibleElements пока [], после завершения — полное поле.
- checkClue(clue) внутри движка проверяет пять типов подсказок относительно скрытого ответа; кандидаты и выбор подсказок ещё не реализованы.
- tests/engine.test.mjs: 5 проходящих тестов размеров, состава строк, независимости двух копий и повторного старта.
- .github/workflows/tests.yml: node --test после push в main, Ubuntu, Node.js 26.13.1. Удалённый результат пока не просмотрен.

## Принятые границы
Слой 3 хранит скрытый ответ, внутренние словари и логику. Слой 2 получает только разрешённые данные, сопоставляет ID картинкам и отображает состояние. Не экспортировать внутренние функции ради тестов. Генерацию проверяем через настоящее действие endGame(), открывающее ответ. Общий getState() обсуждался, но пока реализованы отдельные геттеры.

Каталог и порядок строк постоянны, перемешиваются только колонки. Римские ID roman-I, roman-II, roman-III сохранять с заглавными буквами. Словари единообразно названы PositionById; координаты rowIndex/colIndex. Подсказки given используют columnIndex.

clueCandidates — пять массивов по типам; cluesSelected — один общий массив. Три группы интерфейса формирует слой 2. Значения весов/лимитов не согласованы. Подробности в архитектуре и правилах.

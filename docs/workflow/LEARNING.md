## Быстрые памятки JavaScript

### Object.values()

`Object.values(объект)` возвращает новый массив значений его собственных перечисляемых свойств, без имён свойств.

```javascript
// Массив ссылок на существующие группы кандидатов.
const groups = Object.values(clueCandidates);
// В нашем объекте given — первая группа:
groups[0] === clueCandidates.given; // true
```

Группы и объекты подсказок не копируются. `groups[0].pop()` меняет исходную группу `clueCandidates.given`, а `groups.pop()` — только новый внешний массив ссылок.

### splice()

`массив.splice(начальныйИндекс, сколькоУдалить)` изменяет исходный массив и возвращает массив удалённых элементов.

```javascript
// Удаляем одну выбранную подсказку из исходной группы.
const removedClues = group.splice(randomIndex, 1);
const clue = removedClues[0]; // Сам объект удалённой подсказки.
```

- Второй аргумент `1` — удалить один элемент; `0` или отрицательное число — не удалять ничего.
- Отрицательный первый аргумент отсчитывает начало с конца: `splice(-2, 1)` удаляет предпоследний элемент массива длиной не менее двух.
- Можно вставлять элементы: `splice(index, 0, newItem)` вставляет `newItem` без удаления.

В `addRandomClue`: `totalCount` — общее количество кандидатов; `randomIndex` — общий индекс. При переходе к следующей группе из индекса вычитается длина предыдущей, пока индекс не станет локальным для нужной группы.

Памятки добавлены 2026-11-25 после разбора; это не отметка полного освоения API.

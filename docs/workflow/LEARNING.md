# Обучение в Enstain-game

Этот файл хранит только цели и наблюдаемый прогресс, относящиеся к обучению на проекте Enstain-game. Общий подход помощника к обучению и переносимые предпочтения пользователя описаны в [навыке обучения Assistant Workbench](../../assistant-workbench/skills/learning.md).

## Цели в рамках проекта

- Развивать браузерную игру и изучать JavaScript на практических задачах.
- Учиться формулировать задачи AI, разбирать решения и проверять результат.
- Освоить работу с GitHub с двух компьютеров.
- Освоить автоматические проверки и CI/CD на примере проекта.

## Значимые этапы практики

### 2026-11-16 — первые тесты и CI

- Написаны первые 5 тестов `node:test` и `assert/strict`: размеры, состав строк, независимость копий и повторный старт; пользователь самостоятельно исправлял проверки.
- Разобраны `import`/`export`, копирование строк через `map` и spread, методы `assert`, предусловия и независимость проверок.
- Настроен workflow GitHub Actions для запуска `node --test` после push в `main`.
- Пользователь написал `checkClue` для пяти типов; разобраны ошибки в `given`, названиях top/bottom, ограничениях строк и `between`.

### 2026-11-17 — генерация подсказок и CI

- Пользователь реализовал `given`, временный `selectClues`, `getClues` и вспомогательные `fillPositionById`/`checkClue` в тестах. Сам исправил импорт, `colIndex` и закрытие `forEach`; на тот момент проходили 6 тестов.
- Разобраны callback, `map`, передача функции, стрелочное тело, возврат объекта, `Object.values`, spread и поверхностные копии.
- Пользователь подтвердил успешный ручной запуск CI в GitHub Actions.

### 2026-11-18 — проверки ID и циклическая генерация

- Добавлены проверки независимости массива и объектов `getClues`, формата ID для `given`/`sameColumn`/`leftOf` и уникальности ID через `Set`; на момент записи проходили 9 тестов.
- Разобраны `const`/`let`, `pop`, `Set`/`has`/`add`, `assert.ok`/`equal`/`fail` и диагностические сообщения.
- Разобран тернарный оператор как аналог `?(,,)` в 1С; пользователь применил его для независимой нормализации ID `sameColumn` в тесте.
- При реализации `sameColumn`/`leftOf` пользователь сам исправил пропущенный цикл по строкам, скобки callback и ошибочный вызов `map` для объекта.
- Обсуждён стиль скобок блоков и точек с запятой в циклах, функциях и выражениях.
- Согласовано различать полноту пула кандидатов и правильность выбранного набора; независимый логический анализ, разовые проверки и сохранённые тесты дополняют, но не заменяют друг друга.

## Обозначения игры

В учебных примерах элементы обозначаются в квадратных скобках: [A], [1], [II]. Индексы и номера строк/колонок пишутся без скобок.

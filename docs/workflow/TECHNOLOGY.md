# Технологии и окружение

## Подтверждено

- VS Code + расширение Codex, как сейчас на работе. Дополнительное ПО можно устанавливать.
- ОС дома и на работе — Windows.
- Дома Codex ещё нужно установить и проверить на бесплатном аккаунте. Доступность и лимиты не подтверждены.
- Git + публичный репозиторий GitHub; локальные копии дома и на работе.
- Сейчас только main; commit и push выполняет пользователь.
- Работает один человек поочерёдно с двух компьютеров.

## Направление продукта

Frontend-веб-игра со структурой, учитывающей будущий backend. Язык, библиотеки, сборщик, хранение данных и архитектура пока не выбраны. Знание HTML/CSS и JavaScript само по себе не означает согласование стека.

## Автоматизация

Сначала проверки для обучения и контроля своей работы. Их состав и инструменты выбираются после стека и практических задач. Публикация и автоматический деплой отложены.

## Уточнить перед настройкой

- Версии необходимых инструментов на обоих компьютерах.
- Доступность Codex дома после установки.

Репозиторий публичный: пароли и токены здесь не хранить.

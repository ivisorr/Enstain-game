# Головоломка Эйнштейна

Учебная браузерная логическая игра. Основное поле планируется 6 × 6; разработка начинается с примера 3 × 3. Сейчас в движке реализованы постоянный каталог ID и построение словаря координат. Интерфейс и генератор ещё не реализованы.

Проект также используется для изучения JavaScript, разработки с AI, работы с двух компьютеров и CI/CD. Пока логика работает на frontend; при проектировании учитывается возможный будущий backend.

## Структура проекта

```text
Enstain-game/                    # Корень проекта
├── README.md                   # Описание, состояние и навигация по проекту
├── AGENTS.md                   # Правила AI и порядок чтения контекста
├── .gitignore                  # Исключения из Git
├── Note.txt                    # Личный рабочий буфер пользователя
├── src/                        # Исходный код приложения
│   └── js/                     # JavaScript движка и будущего интерфейса
│       └── engine.js           # Каталог ID и первые функции движка
├── docs/                       # Документация проекта и процесса
│   ├── project/                # Правила, архитектура и исследования игры
│   │   ├── GAME_RULES.md        # Правила поля, подсказок и генерации
│   │   ├── ARCHITECTURE.md      # Слои приложения и структуры данных
│   │   ├── GENERATION_REVIEW.md # Анализ алгоритмов генерации и источники
│   │   └── assets/             # Иллюстрации документации
│   │       └── interface-sketch.png # Предварительный эскиз интерфейса
│   ├── workflow/               # Организация разработки и обучение
│   │   ├── WORKFLOW.md         # Процесс работы и протокол сессий
│   │   ├── LEARNING.md         # Опыт, цели и прогресс обучения
│   │   ├── TECHNOLOGY.md       # Рабочее окружение и инструменты
│   │   ├── TASKS.md            # Задачи, статусы и отложенные вопросы
│   │   └── HISTORY.md          # Итоги сессий и существенные решения
│   └── ai/                     # Контекст для продолжения работы с AI
│       ├── CONTEXT.md          # Краткое актуальное состояние проекта
│       └── HANDOFF.md          # Подробности незавершённого обсуждения
├── css/                        # Существующая папка; назначение уточняется
└── tmp/                        # Временные материалы, ожидающие разбора
```

Дерево отражает основные файлы и папки; содержимое `tmp/` не перечисляется. Файл `ui.js` будет добавлен в `src/js/`, когда начнётся работа над слоем интерфейса.

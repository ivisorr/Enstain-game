# Головоломка Эйнштейна

Учебная браузерная логическая игра. Основное поле планируется 6 × 6; текущий учебный каталог — 4 × 4. Реализованы генераторы всех пяти типов подсказок и случайный обмен их симметричных участников. Пробный отбор берёт до десяти случайных подсказок; достаточность набора пока не проверяется. Логический решатель и интерфейс ещё не реализованы.

Проект также используется для изучения JavaScript, разработки с AI, работы с двух компьютеров и CI/CD. Пока логика работает на frontend; при проектировании учитывается возможный будущий backend.

Подключение движка к HTML-странице и удобный способ запуска пока не настроены. Движок не зависит от DOM, изображений или подписей интерфейса.

Для запуска тестов из корня проекта (требуется Node.js):

```powershell
node --test
```

В `.github/workflows/tests.yml` настроен запуск node --test после push в main и ручной workflow_dispatch (Node.js 26.13.1, Ubuntu). Последний подтверждённый успех на GitHub — 2026-11-17. В последнем локальном запуске прошли 10 тестов, но статистический тест обмена требует пересмотра после сокращения выбора до десяти подсказок: он может случайно падать. Полнота всех пяти генераторов на 4 × 4 проверена отдельно разовым независимым перебором, не сохранённым в CI.

# Навык: напоминание и проверка данных для публичного репозитория

**Модуль:** признан необходимым; включается в профиль проекта отдельно.
**Зрелость:** согласие пользователя перед проверкой — устоявшееся правило; признаки и моменты для напоминания — экспериментальные.

## Рабочее поведение

- Не запускать автоматическую или полную проверку файлов без согласия пользователя.
- Перед push или PR в публичный GitHub-репозиторий предложить пользователю проверку новых и изменённых файлов на публичные данные.
- Если в ходе обычной работы замечены явные признаки секретов, персональных или конфиденциальных данных, не повторять само значение; кратко сообщить категорию и место, затем спросить, хочет ли пользователь провести проверку.
- Если пользователь отказывается, не проводить проверку и продолжить работу в заданных границах.

После согласия проверять только относящиеся к запросу файлы. Сообщать путь и категорию риска, не раскрывая подозрительное значение. Не утверждать, что просмотр обнаруживает все чувствительные данные. Commit и push выполняет пользователь; навык не отправляет данные.

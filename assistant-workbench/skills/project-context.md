# Навык: контекст и передача между сессиями

**Модуль:** признан необходимым; включается в профиль проекта отдельно.
**Зрелость:** экспериментальное; применять как стартовую схему в выбравших навык проектах, проверять на разных типах проектов и уточнять.

Базовый шаблон для выбранного проекта; применять как стартовую схему и адаптировать, если он не подходит:

- `CONTEXT.md` — короткое состояние проекта, важные ограничения и ближайший шаг.
- `HANDOFF.md` — подробности активного незавершённого обсуждения и точка продолжения.
- `TASKS.md` — согласованные задачи и открытые вопросы.
- `HISTORY.md` — принятые решения и итоги; не заменяет чтение изменений кода.

Проверять по практике, какие документы нужны конкретному проекту. Не объединять его состояние с контекстом разработки самого помощника.

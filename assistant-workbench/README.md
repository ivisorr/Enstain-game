# Assistant Workbench — черновик

## Назначение

Это документационная мастерская для разработки переносимого помощника-партнёра и ментора. Папка не является установленным агентом, плагином или техническим пакетом Skills.

В обсуждениях этой работы слово «агент» без уточнения означает именно этот черновик: пользователь пока не использует других агентов.

## Структура

```text
assistant-workbench/                         # Черновик переносимого AI-помощника
├── README.md                                # Назначение, структура и связь с Enstain-game
├── AGENTS.md                                # Подтверждённое общее ядро и правила мастерской
├── CONTEXT.md                               # Краткое состояние черновика и следующий шаг
├── HANDOFF.md                               # Подробный контекст незавершённой темы помощника
├── TASKS.md                                 # Идеи, кандидаты, открытые вопросы и задачи
├── HISTORY.md                               # Принятые решения и итоги разработки помощника
└── skills/                                  # Рабочие модули, включаемые для выбранных проектов
    ├── feature-development.md               # Согласование функциональности и разбор реализации
    ├── learning.md                          # Объяснения, упражнения и наблюдение за навыками
    ├── testing-review.md                    # Сценарии тестов и порядок проверок
    ├── project-context.md                   # Работа с контекстом разных проектов
    └── public-data-review.md                # Напоминание и проверка данных для публичного репозитория
```

Все пять навыков признаны необходимыми модулями. Включение каждого модуля выбирается для отдельного проекта и записывается в его профиле.

## Зрелость правил

- **Экспериментальное** — уже применяется в проекте, который включил навык; формулировку проверяют и уточняют по практике.
- **Устоявшееся** — проверено и применяется как стабильное.
- Идеи, для которых ещё не решено, нужны ли они, хранятся в `TASKS.md` или активном `HANDOFF.md`, вне рабочих навыков.

## Связь с Enstain-game

Корневой `AGENTS.md` Enstain-game направляет к общему ядру и перечисляет навыки, выбранные для этого проекта в `docs/ai/CONTEXT.md`. Правила игры и проектный контекст берутся из документов игры. При работе над разработкой черновика его `CONTEXT.md`, `HANDOFF.md`, `TASKS.md` и `HISTORY.md` читаются как материалы о ходе разработки, а не как дополнительные активные правила.

Настройки навыков могут уточняться по мере работы. Изменения этого черновика и игровых файлов проходят согласованный цикл подтверждения.

## Что сюда не входит

- Игровая механика, архитектура приложения, код и его тесты остаются в Enstain-game.
- Параметры VS Code, Codex, GitHub, CI/CD и авторизация сервисов пока только анализируются; техническую установку не настраиваем.
- Файлы в `skills/` — обычные проектные заметки, а не готовые Codex `SKILL.md`.
